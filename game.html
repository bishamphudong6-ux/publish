JavaScript Flappy Bird Game

This game is a modified version of a Flappy Bird-style JavaScript game created using the W3Schools game tutorial. I customized the original project by adding a background image, scoring system, and improved styling to make it more visually appealing and interactive.

The game is built using HTML5 Canvas and JavaScript and demonstrates important programming concepts such as animation loops, gravity, collision detection, and user input handling for both desktop and mobile devices.

You can view the original tutorial here: W3Schools JavaScript Game Tutorial
